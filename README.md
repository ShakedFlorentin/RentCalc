# הטיול ליפן 🇯🇵

אפליקציית ווב (מותאמת לטלפון, אפשר "להוסיף למסך הבית") לתכנון ומעקב משותף של טיול ליפן.
כל מה שאחד עורך – מתעדכן אצל כולם בזמן אמת.

**לאפליקציה:** https://shakedflorentin.github.io/RentCalc/

- **בית** – ספירה לאחור / "יום X" בזמן הטיול, התוכנית של היום, שעון יפן, המסלול לפי ערים, הזמנת חברים
- **מסלול** – תוכנית לכל יום: עיר, מלון, פעילויות עם שעה, קישור למפה, סימון "בוצע"
- **הזמנות** – טיסות, מלונות, רכבות, כרטיסים, ביטוח + מספרי אישור וקבצים מצורפים (PDF/תמונה)
- **מקומות** – רשימת מסעדות/אטרקציות/חנויות לפי עיר, סימון "היינו", הוספה ליום במסלול
- **רשימות** – משימות לפני הטיסה, ציוד, קניות ביפן, עם אחראי/ת

## טכני

React + TypeScript + Vite, נתונים ב-Supabase (פרויקט `japan-trip`), הרשאות לפי Row Level Security –
רק חברי הטיול (מי שהצטרף עם קוד הטיול) רואים ועורכים אותו.

```bash
npm install
npm run dev
```

פריסה: GitHub Actions בונה ומעלה ל-GitHub Pages בכל push ל-`main`
(צריך פעם אחת: Settings → Pages → Source: **GitHub Actions**).
